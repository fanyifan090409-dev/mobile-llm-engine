## 一、GitHub 调研结论（工具链决策）

| 工具 | Stars | 结论 |
|---|---|---|
| slidev | 48k | Markdown+Vue 幻灯片，设计控制最强，但输出 HTML/PDF，不产原生 PPTX |
| marp | 12.5k | Markdown 直出 PPTX/PDF，但 PPTX 导出样式保真度一般 |
| mermaid / d2 | 90k / 25k | 图语法通用，但自动排版是「默认工程师风」，达不到苹果级视觉 |
| ppt-master | 47k | AI 生成 PPTX——正是要避开的 AI 味，弃 |
| python-pptx | — | 原生 PPTX 全控制，WPS 可编辑，配合自绘 PNG 图 = 版式复用落点 |

**决策**：
- 数据图 → matplotlib + 定制 style 文件 → PNG @2x（一个 style 管全部图 = 风格复用）
- 机制/流程/场景图 → 手写 SVG（元素库 = 元素拆分复用）→ Chrome headless 转 PNG @2x
- PPT → python-pptx 组装原生 16:9 PPTX（版式函数复用），文字内容来自方案 B 大纲，用户在 WPS 里填照片/微调
- 新依赖声明（纪律 #6）：`.venv` 装 matplotlib + python-pptx。用途=图表与 PPT 生成；替代方案=Keynote 手绘（无批量复用能力）。无代码运行时依赖。

## 三、设计系统（元素库，全图共用）

- **色板**：蓝 #0A84FF、绿 #30D158、橙 #FF9F0A、红 #FF3B30、灰阶 #1D1D1F / #6E6E73 / #AEAEB2 / #C7C7CC、浅底 #F5F5F7；图表序列色 蓝→绿→橙→灰。
- **字阶**：图题 28 semibold / 小节 15 semibold / 数据大数字 40-56 bold（等宽数字特性）/ 正文 12-13 / 图注 10；中文 PingFang SC、数字 Helvetica Neue。
- **画布**：1600×900（16:9）@2x 导出；页边距 96；8pt 栅格。
- **复用元素**：
  - 数据卡（label + 大数字 + 单位 + 趋势小箭头）
  - 步骤徽章（绿 ✓ 圆章 = 演示壳过程卡同款，风格与 App 呼应）
  - 场景卡（圆角 20 + 弱底色 + 标题 + 一句话）
  - 来源注脚（「数据来源：SFT17 评测报告 · 2026-11-02」10pt 灰）
- **版式复用**：左右分栏（图 + 结论条）/ 上下（标题 + 图 + 一句结论）；每张图一行结论句。
