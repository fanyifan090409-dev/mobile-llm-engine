# 队友操作指南（纯网页，无需安装任何软件）

> 给队员看。全程只用浏览器，不需要 git 命令行，不需要装软件，不需要会写代码。
> 预计第一次操作 15 分钟，熟练后每次 2 分钟。
> 卡住不要自己硬试，在 Issue 里说一句「卡在第几步」，队长会远程协助。

---

## 0. 准备

1. 一个 GitHub 账号。没有就打开下面这个地址注册（邮箱 + 密码即可）：

```
https://github.com/signup
```

2. 把账号发给队长，队长会把你加成仓库协作者。收到邮件邀请后，点邮件里的 **Accept invitation**。

3. 记住仓库地址：

```
https://github.com/fanyifan090409-dev/mobile-llm-engine
```

---

## 1. 领任务

1. 打开仓库页面，点顶部 **Issues**。
2. 找到标题写着 `[任务]` 并且是你名字的那一条，点进去。
3. 从上到下读完「目标 / 交付物 / 验收标准 / 证据要求」。
4. 在页面最下面的输入框写一句「我接了，预计 X 月 X 日交」，点 **Comment**。
5. 有不懂的地方直接在同一个框里提问，不要私聊——留在 Issue 里才算记录。

---

## 2. 建文件（这是你 90% 的操作）

1. 在仓库主页点右上角 **Add file** → **Create new file**。
2. 文件名输入框里，把任务单给出的路径原样粘进去，例如：

```
docs/aiy27/qa/真机回归-20261115-张三.md
```

   注意斜杠要保留，GitHub 会自动建文件夹。

3. 下面的大框里写内容。**第一行写标题**，例如：

```markdown
# 真机回归报告 — iPhone 15 / iOS 26.1 / 2026-11-15
```

4. 写完后拉到页面最下面，点绿色按钮 **Commit changes**。
5. 弹出的窗口里：
   - 上面一栏写一句话，例如「提交真机回归报告」；
   - 选下面那个选项 **Create a new branch for this commit and start a pull request**；
   - 分支名保持默认就行；
   - 点绿色 **Propose changes**。
6. 页面会跳到「Open a pull request」，标题写清楚，描述框里照着模板填（见第 4 步），最后点 **Create pull request**。

---

## 3. 改已有文件

1. 打开那个文件，点右上角铅笔图标 **Edit this file**。
2. 改完同样点 **Commit changes**，走和第 2 步一样的流程。
3. 如果这个文件已经被你提过 PR 且还没合并，GitHub 会自动把你的新改动加到同一个 PR 里，不用重新提。

---

## 4. PR 描述怎么填

打开 PR 后，描述框里已经有模板，照着填四块：

- **关联任务**：`Closes #12`（把 12 换成你的 Issue 编号）
- **这个 PR 改了什么**：两三句话
- **证据**：截图路径、原话记录、来源文件和具体位置——一条一行
- **AI 参与说明**：写清哪些是智能体起草的，哪些是你实测的。没有 AI 参与就写「无」
- **自查**：三个框都打勾。**没实际做的项不要打勾。**

---

## 5. 评审与返工

1. 队长会在 PR 页面留言。收到邮件通知后回来看。
2. 如果说要改，直接在 **Files changed** 页面点文件右侧的铅笔图标改，或者回到仓库改文件——改动会自动出现在同一个 PR 里。
3. 改完在 PR 下面回一句「已修改，请再看一次」。
4. **不要自己点 Merge**。合并由队长做，这样每个 PR 都有评审痕迹。

---

## 6. 怎么用你的智能体（重点）

正确姿势：

1. 把 Issue 的**整段正文**复制，粘给你的智能体，前面加一句：
   「这是我的任务单。请帮我列出执行步骤清单和需要记录的字段，不要编造任何结果。」
2. 智能体给出清单后，**你去实际执行**（跑测试、访谈同学、核对数字），把真实结果记在纸上或备忘录里。
3. 把真实结果发回给智能体，让它整理成 Markdown 表格或规范文档。
4. **逐句读一遍它整理的内容**，把不对的地方改掉，确认每个数字都是你自己测出来的。
5. 提交时在 PR 的「AI 参与说明」里写清楚：表格与文案由智能体整理，测试结果本人实测。

绝对不要：

- 让智能体「编一份测试报告」然后直接提交；
- 没跑过的项填「通过」；
- 把智能体写的结论当成自己的判断——评审时队长会问细节，答不上来就要打回重做。

---

## 7. 常见问题

**Q：找不到 Add file 按钮？**
A：确认你在仓库主页（地址以 `mobile-llm-engine` 结尾），不是某个文件里面。

**Q：提交后没看到 PR？**
A：去仓库顶部 **Pull requests** 里找，标题是你刚写的那句。

**Q：文件名带中文会不会有问题？**
A：不会，仓库里已经有很多中文文件名。

**Q：写错了想删掉？**
A：不用删，直接在 PR 里改，或者告诉队长在评审时处理。

**Q：一定要用电脑吗？**
A：编辑文字可以用手机浏览器，但截图和上传用电脑方便得多。

**Q：AI 智能体要不要跟队长报备？**
A：不用报备工具，但 PR 里必须写明哪部分由 AI 起草。
