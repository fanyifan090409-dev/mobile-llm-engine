# 训练前后对比评测计划

2026-10-25 定稿。回答用户需求：等 PT2+SFT2 训练完，用我们的量化版与「以前的不量化版」及「不同量化版本的原版」做详细对比，出专业数据版 + 大众可读版。

## 评测矩阵

两个模型族 × 多个量化档位，全部同一台 Mac（Apple M5，Metal）、同一 llama.cpp b11857、同一参数（--jinja、temp 0.7、ctx 2048、max 512 tokens）：

| 模型族 | 档位 |
|---|---|
| 原版 Qwen3-0.6B（Instruct，训练机 models/Qwen3-0.6B） | F16 / Q8_0 / Q5_K_M / Q4_K_M |
| 我们（PT2+SFT2 final，发布候选） | F16 / Q8_0 / Q5_K_M / Q4_K_M / IQ4_XS |

已备好的原版产物（work/）：orig_f16.gguf、orig-Q8_0.gguf、orig-Q5_K_M.gguf、orig-Q4_K_M.gguf。
注：原版基线=Instruct 版（Qwen 改名后 Qwen3-0.6B 仓库=原 Instruct），我们的 PT 即从该权重续训。

## 指标（专业版）

1. **PPL 双域**：目标域（SFT 同源语料 work/eval_corpus.txt）+ 通用域（fineweb2 cmn_Hani 抽样 work/eval_general_corpus.txt，140KB/137 段）
2. **生成质量**（15 题 × 每模型）：规则问题检出（复读/截断/空回复，沿用已修复的 eval_gen 逻辑）；翻译 3 题 chrF 参考分（字符 n-gram F 值，译法容错）；其余 12 题关键词覆盖分（内容要点客观可判）
3. **速度**：llama-bench 提示处理 t/s 与生成 t/s
4. **内存**：GGUF 文件大小 + /usr/bin/time -l 实测峰值 RSS

## 指标（大众版）

- 15 题通过率表（✅/❌）
- 速度换算：每秒生成汉字数（1.6 字/词元估算）+"100 字回复几秒"
- 内存：MB 数 + 占 12GB 手机比例
- 五类任务各挑一题，原版 vs 我们并排展示
- 一句话结论（自动从数据生成）

## 自动化链路（PT2 收段后无人值守）

1. 训练机 watcher（tmux sft2-watch）轮询 pt2 log 出现 `PT2_ALL_DONE` → 启动 run_sft2.sh（train_sft_launch.sh 改：model=pt2 final、out=sft-20261026，2ep lr 1e-5 同 SFT1）
2. SFT2 `TRAINING_FINISHED` → 训练机 convert f16 GGUF（convert_hf_to_gguf）
3. Mac 侧 nohup 轮询链：检测训练机 f16 就绪 → rsync → 量化五档 → eval_compare.py 全矩阵 → generate_report.py → docs/评测/0.6B训练前后对比报告.md
