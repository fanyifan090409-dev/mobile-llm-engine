## 2. 数据策略（三条链）

### 2.1 真题转化链（核心新增，云端大模型）

用户提供真题（PDF/图片/Word）→ 本机提取切题（现有 pdftext/ocr 零安装链）→ **Pro 官方 CodeBuddy CLI（云端大模型）转化**：

- **切题清单先给用户确认**（题号/题面首句/图说明），防错切漏切，确认后批量转化
- 每题产出 1 条解题训练样本 + 3-5 条同构变式（改数据不改解法路径），格式见 §2.4
- 深度推理轨迹：分步带理由（每步写「为什么」）+ 末尾验算自查——对齐 R1 蒸馏路线的可见推理形态
- 真题 20% 留 holdout 做验收集，80% 进训练池
- 变式正确性保障：云端一次产出变式+解答，QC 标记块/公式残缺检查 + Leader 抽检 10%

### 2.2 教师合成链（30B :8003 / 27B :8002，配比重构）

类别与占比重配（数学为主）：

| 类别 | 占比 | 说明 |
|---|---|---|
| ap_calc 微积分 | 40% | 原 SFT18 类别，保留 |
| precalc 美高数学 | 20% | **新增**：Precalculus / Algebra 2 / Trigonometry（微积分前置知识谱系） |
| ap_stats 统计 | 15% | 原类别，降权 |
| ielts 雅思 | 25% | 原类别，降权（亚洲考生低 AI 风格契约不变） |

- solve 类解答要求升级：必须含「思路 → 分步理由 → 验算」，不再是裸步骤
- precalc 需新增：知识点池（单元+子知识点）、构建器、QC 检查（复用 problem_gen 标记契约）
- 历史池防遗忘六类降采样保留（CAPS_SFT18_HISTORY 沿用）

### 2.3 云端补充批次（Pro，已派发进行中）

300 样本（35/25/40 旧配比）照收：ap_calc/ap_stats 部分并入数学池，ielts 部分并入雅思池。完成后 Pro 通道转真题转化链。

### 2.4 格式契约（训练样本 schema）

```json
{"messages": [{"role": "user", "content": "题面…"},
              {"role": "assistant", "content": "【思路】…\n【解答】…\n【答案】…"}],
 "category": "ap_calc|precalc|ap_stats|ielts",
 "form": "solve|problem_gen|…",
 "hash": "sha256(messages,sort_keys)[:16]"}
```

- 解题类：assistant = 【思路】（解题规划，2-4 句）→ 【解答】（分步编号，每步含理由）→ 【答案】（最终结果单独一行）
- 出题类：沿用【题目】【答案】【解答】契约（现有）
- 公式用 LaTeX（$…$），QC 检查孤立 $ / 结尾 \（现有）
- 数学样本同样执行低 AI 腔意识：不写「显而易见」「不难发现」式空话，每步落到实处

### 2.5 符号验证链（SymPy 后验，2026-11-02 用户拍板「可以」）

外挂符号引擎结论：**训练侧接入，推理侧本轮不上**（推理侧符号引擎留给后续版本，本轮 1.7B 靠训练数据质量提正确率）。

- **验证器** `train/synthesize/verify_math.py`：对 ap_calc/ap_stats/precalc 合成样本做答案对拍——
  parse_latex 解析题面与答案 → 题型分类（导数/极限/定积分/不定积分/解方程/求值）→ SymPy 求真实结果与
  teacher 答案在 7 个固定采样点数值对拍（容差 rel/abs 1e-3）。
  **只判可验证子集**：解析失败、级数类、应用题无表达式块、奇点全遇 → skip 不误杀；
  出题轨迹（无答案）天然跳过。违规样本 hash 写 violations.jsonl（附 verify_note）。
- **接入点**：合成完成 → QC（qc_sft.py）→ verify_math.py → assemble_train.py `--exclude violations.jsonl` 过滤进训练池。
- **首轮实测**（本机快照 144 条 + 训练机实时 220 条）：ok 7+ / mismatch 2 / skip 其余；
  2 条 mismatch 人工验算确认 teacher 真错（商法则导数漏分母项、有理式化简漏 (x+2) 因子），验证器有效。
- **变式生成器** `variant_gen.py`（已完成）：从可解析题面做系数/常数/积分限扰动变式 +
  SymPy 自动算真答案，只做多项式/有理式的求导/不定积分/定积分/求值四类
  （根式/超越/多变量/文字题跳过）；40 条冒烟全量 SymPy 复核 0 错。
- **变式解答链** `solve_variants.py`（已完成，等合成后运行）：变式题面 → 30B 数学 teacher
  补写【思路】【解答】【答案】→ 答案与生成时真值硬对拍（比现场算更硬）→ 合格入池，
  不合格重试 1 次仍错丢弃；judge 对拍 40 条回归 0 误杀。运行时机：合成链（占用 :8003）完成后。
