# SFT21 领队模糊指令反问（计划）

> 2026-11-08 起草。起点：SFT20 领队 final（`qwen3-1.7b-sft20-20261106/final`）。
> 目标：模糊/信息不足的指令先反问澄清，不编造事件；明确指令的派单行为保持不变。

## 一、问题证据

SFT20 多模型评测（`train/eval/` 与 Mar 演示）发现：
- 「帮我看下附近的房」「夜跑」这类非明确日程请求，领队直接派单，工人补全成具体事件；
- 缺时间/缺对象的请求（如「提醒我交作业」）也会被猜一个时间执行；
- 明确派单回归 12/12 正常，说明不是派单链坏了，是「该不该派」的判断缺失。

## 二、数据契约

格式沿用 `train/synthesize/cloud_sft20/leader_sft20.jsonl`：
`{"role":"leader","task_type":..., "messages":[system, user, assistant]}`。

新增 `task_type = "clarify"`，样本只有两轮（system + user → assistant 反问），**assistant 输出不含 `<tool_call>`**。

### 模糊类型（每类 250-350 条）

1. **无时间**：有明确动作但缺日期/时刻（「明天提醒我交作业」→ 问几点）。
2. **无对象/地点**：缺事件主体或地点且无法合理默认（「帮我订个会议室」→ 问几点、几个人）。
3. **语义两可**：名词/动词短语，不确定是否要建日程（「看房」「夜跑」「复习」→ 问是不是要安排，哪天几点）。
4. **指代不清**：多轮指代但无上下文（「把那个会改到下午」→ 问哪个会、改到几点）。
5. **矛盾/超范围**：前后时间冲突或超出能力（「昨天提醒我明天」→ 指出矛盾并问正确时间）。

### 正样本（防止过度反问）

- 从 SFT20 领队数据抽 1,200 条完整派单轨迹作为 replay；
- 另造 400 条「一句话信息齐全」的派单样本（含今天日期），保持 12/12 回归；
- 保留 300 条 chat 直答样本（不派单也不反问）。

### 配比

约 1,500 条 clarify + 1,200 replay + 400 完整派单 + 300 chat ≈ 3,400 条；
val 从每类各抽 10%（约 340 条），与训练集不重叠。

## 三、训练配方

- 起点：`checkpoints/qwen3-1.7b-sft20-20261106/final`
- 2 epochs，max-len 2048，per-device-bs 8，grad-accum 8，ZeRO-2，bf16，`--no-think --chunked-ce`
- 学习率沿用 `train_sft.py` 默认（与 SFT20 领队一致）
- 冒烟 3 步必须同时出 loss 与 eval_loss，否则停止
- 产物：`checkpoints/qwen3-1.7b-sft21-<date>/final`，量化 Q5_K_M / Q4_K_M

## 四、验收

- **新模糊集 20 题**：不出现 `<tool_call>`，且回复是问句/澄清（人工逐题过）。
- **清晰派单回归 12 题**：派单 worker 与 task 关键字段正确（复用 SFT20 评测）。
- **chat 直答 8 题**：不派单。
- 训练前后同脚本同温度 0 对比；不达标不量化进池。

## 五、回滚

- SFT20 领队 final 与量化文件保留不动；
- 新模型单独目录；评测不通过则 iOS 继续用 SFT20 领队，SFT21 标记失败并记录原因。

## 六、迭代记录

### v1（2026-11-08，失败）

- 数据 2,800：clarify 1,000 + 派单回放 1,500 + 直答 300；4 epochs / 80 步。
- 结果：模糊 16/20（80%），但**派单 0/11**、chat 8/8、数学 37/69（53.6%）。
- 原因：clarify 占比 36% + 4 epochs，模型学会「一律先反问」；多轮派单轨迹的 loss 被后续回合稀释，单轮派单样本不足。

### v2（SFT21b，在跑）

- 数据 3,330：clarify 600（18%）+ 单轮派单 2,080（含 1,200 合成）+ 多轮派单 300 + chat 350；3 epochs / 72 步。
- 从 SFT20 领队 final 重训（不接 v1 的坏权重）。
- 验收门槛：模糊 ≥16/20、派单 ≥10/11、chat ≥7/8、数学不低于 SFT20 领队的 43/69（允许 ±2 题）。
