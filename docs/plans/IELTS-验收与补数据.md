# 雅思验收与补数据（2026-11-08）

> 目标：把「雅思有没有训练到位」变成可复核的分数，而不是风格抽检。
> 起点：SFT19（学术底模，数学最好 45/69）。

## 一、现状审计

- 训练数据 `data/sft19/ielts.jsonl` 共 2,543 条：写作 1,010、阅读 820、听力 713。
- 写作样本是合成题 + 目标 band 提示（7.5-8），**没有实际 band 标注**，也没有考官评语。
- `data/sft19/holdout/ielts.jsonl` 为空；没有 held-out 写作题集。
- 现有验收只有「不像 AI 腔」的风格抽检，不能回答「能考几分」。

## 二、基线结果（2026-11-08，SFT19 Q5_K_M，温度 0）

12 题全部生成，产物 `train/nightly/work/ielts_writing/sft19-q5-v2/`。客观指标 + 单人粗评：

| 项 | 结果 |
|---|---|
| 字数达标 | 10/12（饼图 145、流程图 112，均 <150） |
| Task 1 数据准确性 | 1/6 完全准确（流程图）；其余 5 题错读、漏读或自相矛盾 |
| Task 2 结构 | 12/12 四段以上，264-431 词 |
| 禁用 AI 词 | 0/12 命中 |
| 粗评 band | Task 1 ≈ 5.0-5.5，Task 2 ≈ 5.5-6.0，总 ≈ 5.5-6.0（未达 6.5） |

典型错法（全部可从产物复核）：

- 折线图：数值抄对了，但把 2000 年的 5% 写成 2020 年，结尾称 C 国「大幅下降」（实际 5%→70%），并编出「A/B 在 2015 年并列 80%」。
- 柱状图：年长者阅读 7 小时 > 年轻人 3 小时，写成「略低于年轻人」；把阅读（3h）列进年轻人前三。
- 饼图：核能 15%→10% 写成「稳定在 10%」；太阳能+风能合计 25% 写成「各自 25%」。
- 表格：法国支出 700 亿 > 西班牙 650 亿，写成反的，还称日本「接近翻倍」。
- 地图：北侧公交站与南侧商业街的位置关系写反。
- Task 2：编出「免费教育会增加学生债务」「19 世纪印刷机」「SFIH 单孩家庭政策」等反事实论证。

结论：现有 2,543 条雅思数据只教会「雅思作文的壳」，没教会图表读数和论证自洽。补数据必须针对这两点，不是再加同类范文。

## 三、验收设计（已落地）

- 题集：`train/eval/ielts_writing_eval.json`，12 题 held-out：
  - Task 1：折线图、柱状图、饼图、表格、流程图、地图各 1；
  - Task 2：观点、讨论、问题解决、利弊、两部分问题、观点（AI 教育）各 1。
- 生成：`train/eval/run_ielts_eval.sh`，温度 0，目标 band 7.0-7.5，亚洲考生真人风格。
- 客观检查：字数、段落、句均长、TTR、禁用 AI 词、观点/数据标记、高频重复词。
- 评分：`train/eval/ielts_band_descriptors.md` 四项 rubric，双评 + 仲裁；评分表自动生成。
- 通过标准（首轮基线后定，暂定）：
  - 总分平均 ≥6.5；
  - 任一 criterion 不低于 6.0；
  - Task 1 平均 ≥6.0，Task 2 平均 ≥6.5；
  - 字数达标率 12/12。

## 四、要补什么数据

> 优先级按 v2 基线重排：先修「读图准确」，再修「论证自洽」，最后才是风格。

### 1. Task 1 图表读数专项（最优先，600 条）

- 六类图形各 100 条：折线/柱状/饼图/表格/流程图/地图；
- 每条 = 数据表 + 正确范文（逐项引用数据、无自相矛盾）+ 一句「这题最容易错在哪」；
- 配 200 条负样本：数据表 + 含典型错读的作文 + 正确改写（教「不要这样写」）；
- 重点覆盖 v2 暴露的错法：年份错位、趋势读反、合计/各自混淆、大小关系写反、位置关系写反。

### 2. band 标注作文（300 篇）

- band 5.5 / 6.0 / 6.5 / 7.0 / 7.5 各 60 篇；
- Task 1 / Task 2 各半；每篇带四项评分 + 一句考官式评语（指出扣分点）；
- 目的：让模型见过「不同分数长什么样」，而不是只见过「目标 7.5-8 的范文」。

### 3. 低分 → 高分改写对（200 对）

- 同一题目、同一观点，band 5.5-6 的原文 → band 7-7.5 的改写；
- 标注改动类型：TR 补展开、CC 换衔接、LR 换搭配、GRA 改复杂句；
- 一半用 v2 基线里的真实错法做起点（读图错、论证反事实）。

### 4. Task 2 论证链专项（150 条）

- 五类题型各 30 条：观点、讨论、问题解决、利弊、两部分问题；
- 每条 = 立场 + 2-3 个「观点→解释→具体例子」链 + 一个让步段；
- 配「反事实检测」：例子必须可核查，不编国家政策/历史事件；
- 一半带 band 7+ 的考官评语。

### 5. 语法/词汇升级对（100 对）

- 中国学生高频错误：主谓一致、冠词、时态、可数不可数、搭配、 Chinglish；
- 每对：错句 → 改句 → 一句原因；
- 目的：LR/GRA 的可解释提升。

### 6. 高分样文（50 篇）

- band 7.5-8.5，带考官式批注（为什么好、哪些表达可复用）；
- 只做风格参考，不要求模型背诵。

## 五、训练计划（数据到位后）

- 起点：SFT19 final（学术线，不接领队，避免派单/反问干扰）；
- 数据（约 3,050 条）：Task 1 读图 600 + 负样本 200 + band 标注 300 + 改写对 200 + T2 论证链 150 + 语法对 100 + 现有雅思写作回放 800 + 学术回放 700；
- 2 epochs，max-len 2048，`--no-think --chunked-ce --save-only-model`；
- 验收：本文件第三节 12 题双评；不达标不替换 SFT19。

## 六、执行顺序

1. ~~跑 SFT19 基线 12 题~~（已完成，v2 见第二节）；
2. 先补 Task 1 读图数据（600+200），训一版 SFT24 验证「读数准确率」是否可拉起来；

## 七、为什么先小步而不是一次全补

v2 证明「读图」是独立且可测的能力缺口，和词汇/句式无关。先用 800 条读图数据做单点验证，成本低、结论干净；如果 1.7B 连读图都拉不动，就没必要再堆 band 标注数据。

## 八、SFT24 读图专项执行记录（2026-11-08）

- 数据：`train/synthesize/gen_ielts_t1.py` 生成 798 条（六类各 133），落到 `train/synthesize/ielts_t1_sft24.jsonl`；训练机路径 `data/train_sft24_ielts_t1/train.jsonl`。
- 生成规则：数字、趋势、大小关系全部由数据表推导；QC 拦截字数 <150、禁用 AI 词、范文数字不在数据表内、段落 <3。
- prompt 与 `train/eval/ielts_writing_eval.json` 同一措辞，避免训练/评测分布漂移。
- 配方：SFT19 final 起点；798 新读图 + 600 旧雅思写作回放 + 699 学术回放 = 2,097（train 1,888 / val 209）；2 epochs，lr 1e-5，bs 128，`--no-think --chunked-ce --save-only-model`。
- 验收：同一 12 题复评，重点逐篇核对 Task 1 的数字与趋势是否与数据表一致；T2 作为回归项。
- 风险：模板化范文可能只学会套句式。若 T1 数据准确率上升而 T2 不变，说明单点有效；若 T1 仍错，说明 1.7B 的读图能力到顶，应转数学工具/更大模型路线。

### SFT24 结果（2026-11-08，Q5_K_M，温度 0）

| 题目 | SFT19 v2 字数 | SFT24 字数 | SFT24 重复 8-gram | 结论 |
|---|---|---|---|---|
| t1-line-internet | 233 | 464 | 236 | 复读循环，趋势写反（称 C 增幅最大、A 垫底） |
| t1-bar-activities | 198 | 140 | 34 | 字数不足 |
| t1-pie-energy | 145 | 507 | 312 | 复读循环，合计/各自混淆 |
| t1-table-tourism | 183 | 354 | 207 | 复读循环，数字关系写错 |
| t1-process-recycling | 112 | 145 | 0 | 字数不足 |
| t1-map-town | 220 | 474 | 296 | 复读循环 |
| t2-opinion-transport | 264 | 127 | 0 | 字数不足、单段 |
| t2-problem-living-alone | 329 | 452 | 1 | 出现 pivotal/multifaceted 禁用词 |

**结论：SFT24 失败，不采用。** 模板化读图数据没有教会「数字绑定实体」，反而把模板句式学成了复读循环；同时把 T2 的篇幅/结构带崩。SFT19 仍是雅思最好基线（粗评 5.5-6.0，T1 数据准确 1/6）。

原因判断：
1. 训练样本句式多样性太低（798 条只有 36 种开头、539 条唯一正文），模型学到的是句式而不是读数；
2. 1.7B 对「中文数据表 → 英文实体/数字映射」的绑定能力不足；
3. 读图是确定性任务，继续用自由生成式 SFT 攻它，投入产出比很差。

下一步只有三条：
1. 真实 band 标注 + 考官评语数据，且必须多句式、多题材（成本最高，但唯一能证明分数提升）；
2. 4B 模型（用户已指示暂缓）；
3. 产品侧做「数据表 → 结构化描述」的确定性工具（类似数学 CAS），模型只负责润色，不负责记数字。

## 九、训练顺序（2026-11-08 拍板）

1. **Task 1 确定性事实管线**（零训练）：结构化数据 → 程序算极值/趋势/排名 → 模型只写 overview 与衔接；验收 T1 数据准确率。
2. **去复读 SFT**：现有 2,543 条过熵率 + 语义去重，T1 改写成同组数据 3-5 种写法；LoRA r16、1 epoch；验收 8-gram 重复 <5、字数达标、不低于 SFT19。
3. **Rubric 条件偏好优化**：真实 band 数据（Kaggle/Mendeley 许可核对后）+ 四维 band 条件造偏好对；SimPO/DPO；验收 12 题盲评 +0.3、反事实论证减少、复读不升。

依据：熵率过滤 2610.01493、DCE 2604.07147、CPT 2506.11702、SimPO 2405.14734、self-correction 综述 2406.01297。

### 第一步结果：事实管线（2026-11-08）

- 事实清单：`train/eval/t1_facts.py`，六类图表；数字、极值、排名、趋势全部由程序算。
- facts→模型（SFT19）：字数 157-213 全部达标，重复 8-gram 0-8，无 SFT24 式复读循环；但数据准确仍只有 1/6（仅流程图），柱状图把 12 写成 9、总数差 10 写成 14，饼图把核能 15% 写成 25%，表格把法国 9000 写成 8000。
- 确定性草稿：`train/eval/t1_draft.py`，六题全部由程序写数字；字数 155-162；checker 无趋势矛盾（仅把总数 29、排名 3 两个派生数标为越界，属正常）。
- **结论：Task 1 不能把数字交给模型写。** 产品侧直接输出确定性草稿；模型只做可选润色，润色必须过「数字/实体不变」diff 校验，不通过就回退草稿。

因此第二步调整为：T1 不再进 SFT，只训 Task 2；现有 2,543 条先过熵率 + 语义去重，T2 用 LoRA r16 训 1 epoch。

### 第二步结果：T2 去复读 LoRA（2026-11-08）

- 数据：Task 2 541 条；熵率过滤丢 81 条（低熵/高压缩比），语义去重 0 条；保留 460 条。
- 配方：SFT19 final + 460 T2 + 699 学术回放 + 300 领队回放 = 1,459（train 1,314 / val 145）；LoRA r16/alpha32，196 层、17.4M 可训参数，1 epoch / 11 步。
- 结果（12 题复评）：T2 六题 332-449 词、4-5 段、8-gram 重复 0、禁用词 0；SFT19 基线 264-431 词、4-5 段。T2 平均词数 375.8（SFT19 345.7），段落 4.83（4.5）。
- 粗评：T2 约 6.0-6.5（SFT19 5.5-6.0）；「免费教育增加学生债务」「SFIH 单孩政策」这类反事实论证消失，但仍有「AI 既能管理导师角色又不能替代教师」的逻辑矛盾。待人工双评确认。
- T1：SFT25 的 T1 130-219 词、部分不足 150，且仍有读数错误；**T1 不再使用模型输出**，走确定性草稿 + 可选润色校验。
- 数学回归：SFT25 47/69（68.1%），高于 SFT19 的 45/69（65.2%）；Calc 17/25、Precalc 18/25、Stats 12/19。T2 LoRA + 学术回放没有伤数学，统计还涨了 3 题。
- 结论：SFT25 可作「T2 专项候选」；T1 走确定性草稿，数学走 CAS，三者按任务路由。工具调用/日期回归未测，暂不替换 SFT19 做通用底模。
